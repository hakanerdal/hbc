Kurulum ve Gereksinimler

Bilgisayarı hazırlama · GitHub'dan alma · Canlıya gönderme

HBC ile mockup tasarlayıp Jira task metinlerini üretmek için Cursor kullanırsınız. Çalışmalarınız GitHub'da saklanır; böylece bilgisayar formatı veya silme durumunda kaybolmaz. Bu sayfa kod bilmeyen iş analistleri için yazılmıştır — teknik terimleri mümkün olduğunca sade anlatır.

1. Cursor kurulumu

  1. cursor.com adresinden Cursor'ı indirip kurun.
  2. Açılışta e-posta ile oturum açın (ekip hesabınız varsa onu kullanın).

2. Git kurulumu (bir kez)

Git, dosyaları GitHub ile eşitleyen küçük bir programdır. Komut ezberlemeniz gerekmez; çoğu işi Cursor yapar. Yine de bilgisayarda kurulu olması şarttır.

  1. Windows: git-scm.com/download/win üzerinden Git for Windows indirin ve kurun.
  2. Kurulumda varsayılan seçenekleri kabul etmeniz yeterlidir (Next / Next / Finish).
  3. Kuruldu mu diye kontrol: Cursor sohbetine şunu yazın —
    Git kurulu mu kontrol et. Kurulu değilse Windows için kurulumu yapmama yardım et.
GitHub hesabı Ekip size bir GitHub daveti göndermiş olmalı. İlk klon / gönderme sırasında tarayıcıda oturum açmanız istenebilir — kurumsal e-postanızla giriş yapın.

3. Projeyi GitHub'dan bilgisayara alma (klon)

Klon = projenin güncel kopyasını bilgisayarınıza indirmek. Zip indirmek yerine bunu kullanın; sonraki güncellemeler ve canlıya gönderme kolaylaşır.

Repo adresi (örnek) Ekip size doğru linki verir. Genelde şuna benzer:
https://github.com/hakanerdal/hbc
Canlı site ise genelde:
https://hakanerdal.github.io/hbc/
  1. Bilgisayarınızda çalışmalar için bir klasör seçin (ör. D:\worx veya Belgelerim).
  2. Cursor'ı açın. Sohbete şunu yapıştırın (klasör yolunu ve repo linkini kendinize göre düzeltin):
    D:\worx klasörüne https://github.com/hakanerdal/hbc reposunu klonla. Sonra bu hbc klasörünü Cursor workspace'e ekle.
  3. İş bitince dosya gezgininde hbc klasörü görünmeli; içinde index.html ve calismalarim olmalı.
Daha önce zip / kopya ile aldıysanız Eski klasörü silmeyin hemen. Yeni klonu ayrı bir yere alın; Cursor'da yeni hbc'yi açın. Eski çalışmanız yoksa ekibe sorun — GitHub'daki kopya asıl kaynaktır.

4. Cursor'da HBC'yi açma

  1. Cursor'da File › Add Folder to Workspace… ile hbc klasörünü ekleyin (üst klasör değil, doğrudan hbc).
  2. Sol dosya ağacında calismalarim görünmeli.
  3. Yerelde gezmek için: Dosya gezgininde hbc → index.html çift tıklayın (Chrome açılır). Cursor'dan değil, Windows klasöründen açın.
  4. Günlük akış: Başlangıç rehberi — metni kopyala → Cursor sohbetine yapıştır.

5. Değişiklikleri GitHub'a gönderme (canlıya yansıtsın)

Cursor'da mockup ürettiniz veya düzelttiniz. Bunlar şimdilik sadece sizin bilgisayarınızda. Arkadaşların ve canlı sitenin görmesi için GitHub'a göndermeniz gerekir.

En kolay yol — Cursor'a yazın:

Yaptığım HBC değişikliklerini commit et ve GitHub'a push et. Kısa bir commit mesajı yaz.

Cursor işi bitirdikten sonra 1–3 dakika bekleyin; canlı site güncellenir. Sayfa eski görünüyorsa tarayıcıda Ctrl+F5 ile yenileyin.

İsteğe bağlı — ekrandan gönderme Sol kenardaki Source Control (dal / çatal benzeri ikon) → değişiklikleri görün → üstteki mesaj kutusuna kısa not yazın (ör. «Kaynak listesi mockup güncellendi») → Commit → ardından Sync veya Push. Tercihen yukarıdaki sohbet cümlesini kullanın; daha az hata payı vardır.

6. Başkasının güncellemesini almak

Arkadaşınız yeni mockup gönderdiyse bilgisayarınızdaki kopya eski kalabilir. Cursor sohbetine:

HBC reposunu GitHub'dan güncelle (pull). Çakışma olursa bana basitçe anlat.

7. Canlı siteyi açma

  1. Tarayıcıda ekibin verdiği adresi açın — örnek: https://hakanerdal.github.io/hbc/
  2. Ana sayfada Çalışmalarım kartlarını görürsünüz; karttan mockup'a girersiniz.
  3. Jira'ya veya mail'e paylaşırken bu canlı linki kullanın (bilgisayarınızdaki file:// yolu değil).
Ne zaman lokal, ne zaman canlı? · Lokal (index.html çift tık): Siz tasarlarken hızlı bakış.
· Canlı (github.io): Müşteri / ekip / Jira paylaşımı; push sonrası güncel sürüm.
