Jira İş Açma

3 dakikalık kılavuz

Task metni hazır kutularda durur. Sen kopyalarsın; metni kendin yazmana gerek yok.

Adımlar

#Ne yaparsın
1Çalışmalarım → modül klasörüne gir (ör. Kaynaktan Musluğa)
2Jira task metinleri sayfasını aç — üstte Backend ve Frontend sekmeleri vardır
3İlgili sekmede task kutusunun sağ üstünden Tümünü kopyala (mockup linki kopyaya dahil değildir)
4Jira'da issue aç → Description (Açıklama) alanına git
5Alttaki Text sekmesine geç → yapıştır (Ctrl+V)
6Visual sekmesine geç → biçimlendirilmiş metni görüntüle ve gerekirse düzenle
7Issue başlığı = kutudaki başlık (ör. [FE] Kaynak Listesi)

Text ve Visual modu

Jira açıklama kutusunun altında iki sekme vardır: Visual ve Text. Kopyaladığın metni önce Text modunda yapıştır; sonra Visual'a geçerek başlıkların ve listelerin düzgün göründüğünü kontrol et. Küçük düzeltmeleri Visual modda yapabilirsin.
  1. Text sekmesini seç (mavi / aktif görünür)
  2. İmleci açıklama alanına getir → yapıştır
  3. Visual sekmesine tıkla → biçimlendirilmiş önizleme açılır
  4. Gerekirse Visual modda son kontrolleri yap → kaydet

Doğrudan Visual modda yapıştırırsan biçim bozulabilir; önce Text önerilir.

BE ve FE

Task metinleri sayfasında Backend ve Frontend ayrı sekmelerdedir. Kutunun başlığında [BE] veya [FE] öneki görünür; hangi sekmede olduğun zaten belli olur.

ÖnekKime
[BE]Backend — arka plan / veri işleri
[FE]Frontend — ekran işleri
