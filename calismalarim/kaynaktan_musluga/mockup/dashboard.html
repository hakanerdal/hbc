1 — Dashboard mockup

kaynaktan_musluga çalışmasında dashboard mockup'ı istiyorum. Menü: Etoloji altında ilk sırada Dashboard (Kaynaklar, Tesisler, Musluklar'dan önce) Harita görünümü: kaynaklar, tesisler ve musluklar aynı haritada görünsün. Kaynaklar: yuvarlak, mavi nokta Tesisler: fabrika ikonu Musluklar: ev ikonu Liste ekranlarındaki ilişkilere göre kesikli çizgi ile bağla: kaynak → tesis (tesis formundaki su kaynakları) tesis → musluk (musluk formundaki tesisler) Üstte kısa legend (kaynak / tesis / musluk / kesikli çizgi anlamı). Sadece dashboard ekranı; Jira task yazma.

2 — Ok yönü (düzeltme)

kaynaktan_musluga dashboard mockup'ında kesikli çizgilerin ucuna ok ekle. Kaynak → tesis çizgilerinde ok tesis tarafına baksın (akış kaynaktan tesise). Tesis → musluk çizgilerinde ok musluk tarafına baksın (akış tesisten musluğa). Legend'da da yön anlaşılsın. Henüz Jira task yazma.

3 — Çizgi görünümü (düzeltme)

kaynaktan_musluga dashboard haritasını sadeleştir. Kesikli çizgileri daha baskın mor renkte yap (ince gri yerine). Oklar ve çizgiler yazı etiketine değil, ikon merkezinden ikon merkezine gitsin. Etiketler ikonun altında kalsın; akış soldan sağa kaynak → tesis → musluk kolonları halinde okunabilsin. Henüz Jira task yazma.
